# Ficshon User Journey

## Principle

Ficshon supports multiple entry styles rather than forcing a single onboarding path.

Users may arrive wanting to explore, create, or try tools first.

Regardless of entry point, the platform should guide users toward creating characters, publishing stories, interacting with others, and continuing their narrative over time.

---

## Entry Modes

### Explorer Mode (Reader-first)

These users want to:
- browse stories
- view characters
- read posts
- discover realms

The platform should:
- surface quality content quickly
- avoid forcing immediate creation
- keep creation visible but optional

---

### Creator Mode (Writer-first)

These users want to:
- make a character
- write something
- generate scenes
- post quickly

The platform should:
- remove friction from character creation
- provide a clean writing space
- make publishing feel immediate

---

### Tool Mode (AI/Workspace-first)

These users want to:
- try the story generator
- test the writing workspace
- explore what the tools can do

The platform should:
- allow tool access without social pressure
- make it easy to turn tool output into a post
- guide them toward character use naturally

---

## First Session Goals

A successful first session is one where the user:

1. Sees something interesting
2. Creates or adopts a character
3. Produces a small piece of content
4. Receives some form of interaction
5. Leaves with a reason to return

---

## Retention Drivers

Users are most likely to return when:

- someone replied to their post
- they want to continue a story
- they want more scenes for their character
- they feel part of a realm or conversation

Early interaction is the strongest retention lever.

---

## Platform Responsibilities

Ficshon should:

- allow exploration without pressure
- make character creation rewarding
- make first publishing easy
- prioritise early interaction
- give users a clear path back into their story

---

## Journey Summary

Ficshon should support:

Explore → Create → Publish → Interact → Return

This journey should remain intact even as new features are added.
